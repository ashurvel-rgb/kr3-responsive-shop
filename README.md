# Учебный frontend-проект

Многостраничный сайт учебного интернет-магазина, выполненный в рамках дисциплины «Фронтенд и бэкенд разработка» и контрольной работы №1 «HTML и CSS: разработка многостраничного сайта».

## Постановка контрольной работы №1

Разработать многостраничный HTML/CSS-сайт интернет-магазина с главной страницей, каталогом, карточкой товара, страницей оформления заявки и контактами. Все страницы должны использовать семантическую разметку, общую навигацию и единый внешний CSS-файл.

## Страницы проекта

- `index.html` — главная страница с преимуществами и популярными товарами;
- `catalog.html` — каталог с фильтрами и сеткой карточек;
- `product.html` — карточка товара и таблица характеристик;
- `order.html` — отдельная страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — единый файл стилей;
- `js/main.js` — логика модального окна и валидации форм;
- `images/` — изображения проекта;
- `sitemap.xml` — карта сайта.
- `.gitignore` — список файлов и папок, исключённых из Git.

## Реализовано

- семантическая HTML-разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- общая навигация и хлебные крошки на внутренних страницах;
- БЭМ-структура классов для шапки, меню, карточек, форм, кнопок и подвала;
- Flexbox для навигации и элементов интерфейса;
- CSS Grid для карточек, каталога, страницы товара и формы заказа;
- CSS-переменные для цветов, отступов и скруглений;
- адаптивная раскладка для планшетов и телефонов;
- состояния `:hover`, `:focus-visible`, `:disabled` и подсветка ошибок;
- модальное окно заказа на главной странице;
- отдельная форма заказа с HTML- и JavaScript-валидацией;
- доступная таблица характеристик с `caption`, `thead` и `tbody`;
- Open Graph-теги и карта сайта.

## Самостоятельные улучшения

- добавлены модификаторы БЭМ для популярных товаров и скидок;
- товар из ссылки автоматически выбирается на странице заказа;
- JavaScript безопасно работает на всех страницах сайта;
- добавлены адаптивные стили и удобная мобильная навигация.

## Проверка проекта

1. Открыть `index.html` и проверить переходы по меню.
2. Открыть `catalog.html` и перейти из карточки на `product.html`.
3. Проверить таблицу характеристик и переход на `order.html`.
4. Отправить корректно заполненную форму заказа.
5. Проверить `contacts.html` и мобильное отображение страниц.
6. В терминале VS Code выполнить:

```sh
git status
git log --oneline --graph --decorate
git remote -v
```
