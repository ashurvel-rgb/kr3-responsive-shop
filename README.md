# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Проект представляет собой адаптивную версию многостраничного сайта учебного интернет-магазина. Интерфейс построен без CSS-фреймворков и корректно перестраивается для телефонов, планшетов, ноутбуков и больших экранов.

## Реализованная адаптивность

- до 639px карточки выводятся в одну колонку;
- с 640px карточки выводятся в две колонки;
- с 768px меню становится горизонтальным, а форма — двухколоночной;
- с 900px hero-блок становится двухколоночным;
- с 1024px каталог получает боковой sticky-фильтр, а карточки — три колонки;
- с 1280px сетка поддерживает четыре колонки;
- изображения не выходят за пределы контейнеров;
- таблица прокручивается внутри собственного контейнера без горизонтального скролла страницы.
